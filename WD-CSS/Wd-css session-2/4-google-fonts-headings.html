Poppins for every heading

This paragraph is set in Roboto. Notice how the heading above feels bold and geometric while this body text feels neutral and easy to read at length — that contrast is the whole point of pairing two fonts.

Why pair two typefaces?

A display font (Poppins) gives headings personality and hierarchy, while a workhorse font (Roboto) keeps long paragraphs comfortable to read. Using the same font for everything can feel flat; using more than two can feel chaotic.

A smaller heading, same rule applies

  • Every heading tag — h1 through h6 — inherits Poppins automatically.
  • Every paragraph and list item inherits Roboto automatically.
  • No inline styles were needed; it's all handled by element selectors in CSS.

The CSS

h1, h2, h3, h4, h5, h6 {
  font-family: 'Poppins', sans-serif;
}
p, li {
  font-family: 'Roboto', sans-serif;
}
