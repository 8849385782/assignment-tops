A gradient hero built with plain CSS — no images, no canvas — just linear-gradient() and two Google Fonts.

Get started

How it works

  • background-image: linear-gradient(135deg, #6D28D9, #DB2777) paints the two-stop diagonal gradient.
  • Sora (weight 800) is used only on the <h1> for a bold display headline.
  • Inter (weight 400/500) is used on the subtitle and button for clean readability.
  • Text color is set to white / near-white so it stays readable against the dark gradient.
