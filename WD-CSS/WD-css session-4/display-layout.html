Floats vs. Flexbox

Floats were originally designed to wrap text around images, not to build page layouts — using them for columns means fighting collapsing parents, needing manual clearfix hacks, and getting no real control over vertical alignment or equal-height columns.

They also make responsive reordering and gap spacing awkward, since floated elements only understand "left" and "right", not a true row/column model.

Flexbox would simplify the two-column layout above to just one rule on the parent: display: flex; justify-content: space-between; gap: 20px; — no floats, no clearfix hack, and the columns can even be told to stretch to equal height automatically with align-items: stretch.
